# AnatoQuizUp Doc

O AnatoQuiz é uma plataforma gamificada desenvolvida para melhorar o aprendizado de estudantes de medicina e entusiastas de anatomia radiológica.

Este repositório tem como objetivo manter a documentação do projeto, reunir os artefatos utilizados durante o desenvolvimento e orientar futuros colaboradores.

## Pré-requisitos

- python 3.10 ou superior
- pip 
- mkdocs


## Executando

Para executar o projeto, depois de clonado crie o ambiente virtual:

```bash
python3 -m venv .venv
```

Instale as dependências:

```bash
pip install -r requirements.txt
```

Suba o servidor local:

```bash
mkdocs serve
```

Acesse no navegador:

```text
http://127.0.0.1:8000
```
